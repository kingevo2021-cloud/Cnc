# APPZONE — نشر مجاني

هذه النسخة هي واجهة HTML مستقلة، ويمكن نشرها مجانًا على GitHub Pages.

## من الهاتف
1. أنشئ حسابًا في GitHub.
2. أنشئ Repository جديدًا باسم `appzone`.
3. ارفع `index.html` الموجود في هذا المجلد.
4. افتح Settings → Pages.
5. اختر Deploy from a branch ثم `main` و`/root` ثم Save.
6. افتح الرابط الذي يظهر لك.

مهم: هذه النسخة تعمل كواجهة Frontend فقط. لوحة الإدارة وقاعدة البيانات والرفع الحقيقي للملفات تحتاج Backend وقاعدة بيانات، وهي موجودة في مشروع APPZONE_PRODUCTION_READY.
